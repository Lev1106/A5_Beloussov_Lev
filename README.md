# Smart Campus Room Availability Checker

Assignment 5 — Software Engineering. React, TypeScript and Vite.

Five fictional campus rooms. Read-only availability checks with time validation, booking conflicts, capacity and equipment filters.

## Run

Requires Node.js 22+ and npm.

```sh
npm ci
npm run dev
```

## Tests and checks

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

42 automated tests cover the availability rules and regressions. The project has no credentials or external database.
