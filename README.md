# Smart Campus Room Availability Checker

React / TypeScript / Vite app for campus-room availability.

## Run

Requires Node.js 22+ and npm.

```sh
npm ci
npm run dev
```

## Verify

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

This baseline corresponds to the final Assignment 4 project: [A4_Beloussov_Lev](https://github.com/Lev1106/A4_Beloussov_Lev), commit `c044e10`.
